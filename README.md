# FastAPI Portfolio API

## Overview

This project is a demonstration of a modern RESTful web application built with **FastAPI**, **SQLAlchemy**, and **SQLite**. It showcases how to develop a lightweight, asynchronous backend API using Python while following a clean and modular project structure.

The application demonstrates fundamental CRUD (Create, Read, Update, Delete) operations and serves as a foundation for larger projects such as inventory systems, portfolio applications, AI-powered services, and cybersecurity platforms.

## Technologies Used

* Python 3
* FastAPI
* Uvicorn
* SQLAlchemy (Async ORM)
* SQLite
* Jinja2
* HTML5
* CSS3
* JavaScript

## Features

* Create new items
* View all items
* Update existing items
* Delete items
* SQLite database integration
* Asynchronous API endpoints
* Interactive API documentation using Swagger UI
* Modular project architecture

## Running the Project

Activate the virtual environment and start the development server:

```bash
uvicorn app.main:app --reload
```

Open your browser:

* Home: http://127.0.0.1:8000
* API Documentation: http://127.0.0.1:8000/docs

## Repository Notice

Due to the overall size of this project (including the virtual environment and supporting files), the complete project has **not** been uploaded directly to GitHub.

Instead, the **entire project folder is provided as a ZIP archive**, which contains all project files, dependencies, and resources required to run the application locally.

Please download and extract the ZIP file before opening the project in Visual Studio Code.
